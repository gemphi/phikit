# Demo Step Documentation Index

This folder contains the 16-step guided demo tour for Reality Composer Pro.
Each step is documented with narration text, ASCII layout diagrams, and action references.

## Steps

| # | Step | Panel/Feature | Description |
|---|------|---------------|-------------|
| 01 | Welcome Window | WelcomeView | Clean start — Create / Open / Demo |
| 02 | Editor Layout | EditorWindow | Full window with Hierarchy + Viewport + Inspector |
| 03 | Menu Bar | MenuBar | File / Edit / Insert / Object / View / Appearance / Window / Help |
| 04 | Toolbar | HeaderView | Traffic lights + Scene tabs + Gizmo mode buttons |
| 05 | Hierarchy Panel | OutlineView | Entity tree with expand/collapse |
| 06 | 3D Viewport | Viewport | Camera orbit, zoom, pan — entity selection |
| 07 | Inspector Panel | Inspector | Transform + Material + Physics sections |
| 08 | Project Browser | ProjectBrowser | Asset grid with folders + thumbnails |
| 09 | Shader Graph | ShaderGraphView | Node-based material editor |
| 10 | Timeline | TimelineView | Keyframe animation editor |
| 11 | Audio Mixer | AudioMixer | Channel strips with volume/pan |
| 12 | Statistics | Statistics | FPS, draw calls, triangle count |
| 13 | Content Library | ContentLibrary | Built-in primitives + materials + textures |
| 14 | Appearance Menu | Menu > Appearance | Mode / Scheme / Surface / Color / Typography / Layout |
| 15 | Material Inspector | MaterialInspector | PBR properties: base color, roughness, metallic |
| 16 | Export & Build | File > Export | Package scene for deployment |
