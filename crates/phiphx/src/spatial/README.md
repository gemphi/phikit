# spatial

PhiQui — Native Rust GPUI 3D Spatial UI & Mesh Engine

Callers enter through [`phx::Phx`](../phx/README.md); this folder is one of its parts.

## Files

| File | What it is |
|---|---|
| `mesh_converter.rs` | Rust Mesh Space Converter — 2D BUIKit Panel ↔ 3D Spatial Mesh Converter |
| `mod.rs` | PhiQui — Native Rust GPUI 3D Spatial UI & Mesh Engine |
| `spatial_animator.rs` | 60fps Spring Interpolation & 3D Spatial Matrix Projection Engine for PhiQui |
| `spatial_bui.rs` | Spatial BUIKit Components Constructed From 3D Spatial Mesh Objects |
| `spatial_card.rs` | 3D Spatial Card Panel GPUI Element for PhiQui |
| `spatial_element.rs` | 3D Spatial UI Elements Constructed Directly & Recursively From Geometry Mesh Objects |
| `spatial_object.rs` | Native Rust 3D Spatial Object & Geometry Mesh Buffer Representation |
| `spatial_scene.rs` | 3D Spatial Scene Container for PhiQui GPUI Engine |
