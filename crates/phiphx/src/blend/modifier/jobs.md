- [x] **`clone_box` — a per-frame stack, Blender's own answer** (batch 192, from `ModifierTypeInfo.copy_data` / `BKE_modifier_copydata_generic`). The open question was how a frame gets its own driven settings when `BlendSkinSource` is shared behind an `Arc`: interior mutability, a clone, or a per-frame cache. Blender settles it — the depsgraph evaluates a **copy** of the object and the drivers write into that copy, never into the file's stack. So `BModifier::clone_box` on all nine types, and `BlendSkinSource::evaluate_driven(deformed, world, driven)` clones the tail, lands that frame's settings on the clone, re-asks `is_disabled`, and runs it. `driven` empty clones nothing, so the open path is unchanged. Blender's copy ends with *"Runtime fields are never to be preserved"*, so a clone starts with an empty cache — which is exactly right for `BSubsurf`'s topology tables, since a clone may be handed a different mesh
