# Page Documentation: Timeline Space

## Overview
The **Timeline** page space provides playback controls and keyframe visualization.

## UI Elements
- **Header**: Contains playback transport controls (Play, Pause, Step Forward/Back, Jump to Start/End).
- **Auto-Keying Toggle**: A recording button icon that automatically inserts keyframes for modified properties.
- **Scrub BArea**: Displays the current frame numerically and allows dragging the playhead to scrub through time.
- **Keyframe Track**: Displays summary diamonds indicating frames where the selected object has animated properties.

## Context Sync
- Changes to the current frame in the Timeline immediately trigger a scene evaluation and viewport refresh in the 3D Viewport.
