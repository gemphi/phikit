# Page Documentation: Sculpting Workspace

## Overview
The **Sculpting** workspace page transforms the editor into a digital clay sculpting interface.

## UI Layout Composition
```
┌──────────────────────────────────────────────┬───────────────────────────────┐
│ Top Menu Bar Header                          │ Workspace Tabs Strip          │
├──────────────────────────────────────────────┼───────────────────────────────┤
│                                              │ Outliner Space                │
│ 3D Viewport Space                            │                               │
│ (Locked to Sculpt Mode, MatCap Shading)      ├───────────────────────────────┤
│                                              │ Properties Space              │
│                                              │ (Active Tool, Workspace tabs) │
└──────────────────────────────────────────────┴───────────────────────────────┘
```

## Key Interactions
- **T-Panel**: Displays the sculpt brush palette vertically.
- **Header**: Exposes brush radius, strength, falloff, and Dyntopo parameters.
- **Navigation**: Optimized for tablet pen interaction and rapid view rotation without disrupting brush flow.
