# Page Documentation: File Browser Space

## Overview
The **File Browser** page space is the primary interface for opening, saving, importing, and exporting files. It also functions as the Asset Browser when appropriately configured.

## UI Elements
- **Navigation Bar**: Top header with directory breadcrumbs, back/forward history, up directory, and search filter.
- **Source List (Left Column)**: Standard system directories (Home, Desktop, Documents), mounted drives, and custom bookmarks.
- **Main View**: Displays files and directories. Supports List View (details) and Thumbnail View (previews, especially useful in Asset Browser mode).
- **Operator Panel (Sidebar/Bottom-Left)**: Context-sensitive settings. For example, if "Export OBJ" is active, this panel shows OBJ export options (e.g., Apply Modifiers, Forward Axis).

## Functionality
- Filters files by extension type (e.g., show only `.blend` files or image formats).
- Used extensively during file IO operations triggered from the main `File` menu.
